Lo schema che ti consiglio
Io userei tre tabelle:


            Taxi                ( un taxi è associato a molti trip, ma un trip ha un solo taxi )
            |
            | 1 : N
            |
            Trip                ( un viaggio può avere molti punti GPS, ma ogni punto GPS appartiene a un solo viaggio )
            |
            | 1 : N
            |
            GPSPoint

Il ragionamento è naturale:
- un taxi può fare molti viaggi;
- ogni viaggio appartiene a un taxi;
- ogni viaggio contiene molti punti GPS.
Questa struttura è particolarmente adatta perché la POLYLINE è una struttura annidata e 
la consegna stessa sottolinea che deve essere trasformata e memorizzata con attenzione.


TAXI                                        la tabella taxi in realtà è omittibile, dato che non ha altre cose

        CREATE TABLE Taxi (
            taxi_id BIGINT PRIMARY KEY
        );


TRIP ( non è quella finale, sam la tua trip ha campi in più )


        CREATE TABLE Trip (
            trip_id BIGINT PRIMARY KEY,

            taxi_id BIGINT NOT NULL,

            call_type CHAR(1) NOT NULL,

            origin_call BIGINT NULL,

            origin_stand INT NULL,

            start_time DATETIME NOT NULL,

            day_type CHAR(1) NOT NULL,

            missing_data BOOLEAN NOT NULL,

            point_count INT NOT NULL,

        

            distance_km DOUBLE NULL,

            FOREIGN KEY (taxi_id)
                REFERENCES Taxi(taxi_id),

            CHECK (call_type IN ('A', 'B', 'C')),

            CHECK (day_type IN ('A', 'B', 'C')),

            CHECK (
                origin_call IS NULL
                OR call_type = 'A'
            ),

            CHECK (
                origin_stand IS NULL
                OR call_type = 'B'
            )
        );


    GPS POINT 

            CREATE TABLE GPSPoint (
            trip_id BIGINT NOT NULL,        

            point_index INT NOT NULL,       

            longitude DOUBLE NOT NULL,
            latitude DOUBLE NOT NULL,

            PRIMARY KEY (trip_id, point_index), 

            FOREIGN KEY (trip_id)
                REFERENCES Trip(trip_id)
                ON DELETE CASCADE,          

            CHECK (longitude BETWEEN -180 AND 180),
            CHECK (latitude BETWEEN -90 AND 90)
        );
